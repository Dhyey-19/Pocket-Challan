# Pocket Challan

Web-based project with a local SQLite database.

## Run

1. Install dependencies:
   - `npm install`
2. Start the server:
   - `npm start`
3. Open `http://localhost:3000`.

## Build client package (no Node/npm required on client)

1. Install dependencies:
   - `npm install`
2. Build the client package:
   - `npm run build:client`
3. Send this file to client:
   - `dist/PocketChallan-Client.zip`
